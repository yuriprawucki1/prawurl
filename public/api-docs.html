PrawURL Public API

The public API is hosted at https://api.prawurl.com.

For the machine-readable description, see OpenAPI 3.1.

Health

GET /health returns the API service health status.

Resolve a short link

GET /public/resolve/{alias} returns the redirect, password requirement, block status, or not-found result for an alias.

Unlock a short link

POST /public/resolve/{alias}/unlock accepts a JSON object with a password string.
